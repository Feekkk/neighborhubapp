# NeighborHub

NeighborHub is a cross-platform Flutter application designed to help communities manage users, events, and resources efficiently. It provides both admin and user portals with modern UI, secure authentication, and robust management features.

## Features

- **User Portal:**  
  - View announcements, events, and resources  
  - Profile management  
  - Feedback and support

- **Admin Portal:**  
  - User management (add, assign, verify)  
  - Community guidelines and responsibilities  
  - Secure access and data protection

- **Cross-Platform Support:**  
  - Android, iOS, Web, Windows, Linux, macOS

- **Modern UI:**  
  - Responsive layouts  
  - Custom widgets and themes
